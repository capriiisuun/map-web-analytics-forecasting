# 📊 Web Audience Analytics & Forecasting

A Business Intelligence and Machine Learning project for web audience analysis and session forecasting, developed as part of an internship project at Maghreb Arab Presse (MAP).

## 🎯 Project Objectives

- Analyze website visitors, sessions, and audience engagement.
- Prepare and explore data using Python and Pandas.
- Build an interactive Business Intelligence dashboard with Power BI.
- Develop a Machine Learning model to forecast website sessions.
- Visualize forecasts through a Streamlit application.

## 🛠️ Technologies

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn, Random Forest
- **Data Visualization:** Power BI, Plotly, Matplotlib
- **Web Application:** Streamlit
- **Data Formats:** CSV, Excel

## 🏗️ Project Workflow

1. Data preparation and exploration.
2. Audience analysis and KPI calculation.
3. Dashboard development with Power BI.
4. Model training and evaluation.
5. Forecast visualization using Streamlit.

## 📁 Project Structure

- `analyse.py` — Data analysis and processing.
- `app.py` — Streamlit application.
- `data/` — Input data, subject to publication authorization.
- `previsions_sessions.csv` — Forecast output.
- `requirements.txt` — Python dependencies.
- `MAP_ML_Project/` — Additional project files, if applicable.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/capriiisuun/map-web-analytics-forecasting.git
cd map-web-analytics-forecasting
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch the Streamlit application

```bash
streamlit run app.py
```

Make sure the required data files and dependencies are available before running the application.
